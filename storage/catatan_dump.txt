3. Instal Laravel Sail
Pasang Sail:
composer require laravel/sail --dev
Jalankan instalasi:
php artisan sail:install
Pilih service:
pgsql
redis
mailpit
Untuk tahap pertama, jangan memasukkan terlalu banyak service. Object storage, search engine, dan monitoring dapat ditambahkan setelah fungsi dasar berjalan.
Jalankan container:
./vendor/bin/sail up -d
Laravel Sail menggunakan file compose.yaml di root project dan menyediakan wrapper untuk menjalankan PHP, Composer, Artisan, dan Node di dalam container. 
Buat alias agar perintah lebih singkat:
echo "alias sail='sh \$([ -f sail ] &amp;&amp; echo sail || echo vendor/bin/sail)'" &gt;&gt; ~/.bashrc
source ~/.bashrc
Sekarang gunakan:
sail up -d
sail php --version
sail artisan --version

11. Implementasikan organisasi dan tenant context
Gunakan URL berbasis organisasi:

Buat middleware:

Tanggung jawab middleware:
Mengambil organisasi dari parameter URL.

Menyimpan organisasi aktif ke request/container. 
Mengaktifkan tenant ID untuk permission. 
Menolak akses dengan HTTP 403 bila bukan anggota. 
Contoh sederhananya:
&lt;?php
namespace App\Http\Middleware;
use App\Models\Organization;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;
final class ResolveOrganization
{
    public function handle(Request $request, Closure $next): Response
    {
        /** @var Organization $organization */
        $organization = $request-&gt;route('organization');
        $isMember = $organization-&gt;members()
            -&gt;whereKey($request-&gt;user()-&gt;id)
            -&gt;wherePivot('status', 'active')
            -&gt;exists();
        abort_unless($isMember, 403);
        app()-&gt;instance(Organization::class, $organization);
        return $next($request);
    }
}
Route:
Route::middleware(['auth', 'verified'])
    -&gt;prefix('o/{organization:slug}')
    -&gt;scopeBindings()
    -&gt;group(function (): void {
        Route::middleware(ResolveOrganization::class)-&gt;group(function (): void {
            Route::get('/projects', [ProjectController::class, 'index']);
            Route::get('/projects/{project}', [ProjectController::class, 'show']);
        });
    });
Gunakan scoped binding agar project harus berasal dari organisasi aktif.

Gunakan gap awal:

Perhitungan:

Action MoveTask harus:

Memperbarui status dan rank.

Contoh inti:
return DB::transaction(function () use ($task, $data, $actor): Task {
    $lockedTask = Task::query()
        -&gt;whereKey($task-&gt;id)
        -&gt;lockForUpdate()
        -&gt;firstOrFail();
    if ($lockedTask-&gt;version !== $data-&gt;expectedVersion) {
        throw new TaskVersionConflict();
    }
    $rank = $this-&gt;rankCalculator-&gt;calculate(
        beforeTaskId: $data-&gt;beforeTaskId,
        afterTaskId: $data-&gt;afterTaskId,
    );
    $lockedTask-&gt;update([
        'status_id' =&gt; $data-&gt;statusId,
        'rank' =&gt; $rank,
        'version' =&gt; $lockedTask-&gt;version + 1,
    ]);
    TaskMoved::dispatch($lockedTask, $actor);
    return $lockedTask-&gt;refresh();
});
